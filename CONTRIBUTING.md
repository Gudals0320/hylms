# Contributing

Use Python 3.12 on Windows, a separate virtual environment, and synthetic fixtures. Run the complete unittest suite and public-tree checker before submitting a change. Do not connect CI or a pull-request test to real LMS, notification or calendar credentials.

Keep changes scoped and preserve independent QA, strict packet binding, bounded correction attempts, wrong-owner rejection and single-occurrence admission. Never turn a validation failure into a fabricated QA pass. Include a regression test for behavioral changes.

Do not paste personal announcements, submissions, screenshots, topic names, account identifiers or raw logs into an issue. A minimal synthetic reproduction should retain the relevant shape and failure while replacing private values. Configuration examples must remain examples, not a working person's settings.

Contributions are accepted under the repository's MIT license. Do not submit third-party code or course material unless its redistribution rights are established and any required notices are included.
